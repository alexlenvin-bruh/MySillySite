ML с нуля: k-средних на чистом Python

10 июля 2026 #python#ml#numpy

Библиотеки вроде scikit-learn делают машинное обучение слишком простым. Иногда полезно реализовать алгоритм руками, чтобы понять, как он работает изнутри. Сегодня — k-means (k-средних) на чистом Python + NumPy.

Идея алгоритма

Дано: набор точек в n-мерном пространстве. Нужно разбить их на k кластеров так, чтобы сумма квадратов расстояний от точек до центров их кластеров была минимальной.

  1. Инициализируем k центров случайно (или умно — k-means++).
  2. Повторяем до сходимости:
    • Каждую точку относим к ближайшему центру.
    • Пересчитываем центры как среднее точек кластера.

Реализация с нуля

import numpy as np
import matplotlib.pyplot as plt

class KMeans:
    def __init__(self, k=3, max_iters=100, tol=1e-4):
        self.k = k
        self.max_iters = max_iters
        self.tol = tol
        self.centroids = None
        self.labels = None

    def fit(self, X):
        n_samples, n_features = X.shape

        # Инициализация: случайные центры из данных
        rng = np.random.default_rng(42)
        idx = rng.choice(n_samples, self.k, replace=False)
        self.centroids = X[idx].copy()

        for iteration in range(self.max_iters):
            # Шаг 1: назначение точек к ближайшему центру
            distances = np.linalg.norm(X[:, np.newaxis] - self.centroids, axis=2)
            self.labels = np.argmin(distances, axis=1)

            # Шаг 2: пересчёт центров
            new_centroids = np.array([
                X[self.labels == i].mean(axis=0) 
                if np.sum(self.labels == i) > 0 
                else self.centroids[i]
                for i in range(self.k)
            ])

            # Проверка сходимости
            shift = np.linalg.norm(new_centroids - self.centroids)
            self.centroids = new_centroids

            if shift < self.tol:
                print(f"Сошлось за {iteration + 1} итераций")
                break

        return self

    def predict(self, X):
        distances = np.linalg.norm(X[:, np.newaxis] - self.centroids, axis=2)
        return np.argmin(distances, axis=1)

    def inertia(self, X):
        """Сумма квадратов расстояний до центров — метрика качества."""
        distances = np.linalg.norm(X - self.centroids[self.labels], axis=1)
        return np.sum(distances ** 2)


# --- Тест ---
from sklearn.datasets import make_blobs

X, y_true = make_blobs(n_samples=300, centers=4, cluster_std=0.6, random_state=42)

kmeans = KMeans(k=4)
kmeans.fit(X)

print(f"Inertia (ручная): {kmeans.inertia(X):.2f}")

# Сравним со sklearn
from sklearn.cluster import KMeans as SKKMeans
sk_kmeans = SKKMeans(n_clusters=4, random_state=42, n_init=10).fit(X)
print(f"Inertia (sklearn): {sk_kmeans.inertia_:.2f}")

Ключевые моменты

  • Инициализация важна. Случайные центры могут дать плохой результат. В sklearn используется k-means++ — умная инициализация, которая выбивает центры подальше друг от друга.
  • Сходимость гарантирована, но к локальному минимуму. Запускайте несколько раз с разными начальными условиями.
  • Метрика inertia — полезна для выбора k (метод локтя).

Метод локтя

inertias = []
K_range = range(1, 10)

for k in K_range:
    km = KMeans(k=k).fit(X)
    inertias.append(km.inertia(X))

# Ищем "локоть" — точку, где уменьшение inertia замедляется

Итог

Ручная реализация k-means занимает ~40 строк и даёт полное понимание алгоритма. Разница inertia с sklearn обычно в пределах погрешности округления. Попробуйте добавить k-means++ инициализацию — это отличное упражнение.
