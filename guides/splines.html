Сплайны: как заставить кривую вести себя прилично

23 июля 2026 #численные-методы#python#матан

Представьте: у вас есть несколько точек, и вам нужно провести через них плавную кривую. Можно соединить всё прямыми отрезками — получится ломаная. Грубо, некрасиво, производная скачет на каждом стыке. Можно взять один большой полином, который проходит через все точки — но это полиномиальная интерполяция, и она умеет взрываться на краях (привет, явление Рунге). А можно сделать красиво — и тут приходят сплайны.

Что такое сплайн

Сплайн — это кусочно-заданная функция: на каждом промежутке между контрольными точками своя формула (обычно полином), и в местах стыков всё аккуратно склеено.

Несколько терминов, которые будут встречаться:

  • Контрольные (опорные) точки — точки, в которых известно значение функции. По ним строятся фрагменты сплайна.
  • Контрольная ломаная — ломаная, соединяющая контрольные точки. Фактически это линейный сплайн — самый простой случай.
  • Степень сплайна — максимальная степень использованных полиномов.
  • Гладкость — максимальный порядок непрерывной производной. Чем выше, тем «плавнее» стыки.
  • Дефект — разность между степенью и гладкостью. Ломаная — это сплайн степени 1 и дефекта 1.

Нас интересует кубический сплайн: степень 3, гладкость 2. Это значит, что на каждом отрезке — кубический полином, а в точках склейки совпадают сами значения, первая и вторая производные.

Задача

Нужно построить кубический сплайн для функции \(\cos(x^2)\) на отрезке \([0, 5]\) — для двух сеток: с \(n = 5\) и \(n = 25\) узлами. Потом сравнить, насколько сплайн «промахивается» относительно настоящей функции.

Как это работает

На каждом отрезке \([x_{k-1},\, x_k]\) сплайн выглядит как:

$$S(x) = a_k + b_k(x - x_{k-1}) + c_k(x - x_{k-1})^2 + d_k(x - x_{k-1})^3$$

Коэффициенты \(a\) — это просто значения функции в узлах. А вот чтобы найти \(b\), \(c\), \(d\), нужно решить систему уравнений. Для равномерной сетки (шаг \(h\) одинаковый) она выглядит так:

$$c_{k-1} \cdot h + 2c_k \cdot (h + h) + c_{k+1} \cdot h = 3\left(\frac{y_{k+1} - y_k}{h} - \frac{y_k - y_{k-1}}{h}\right)$$

Это даёт трёхдиагональную матрицу — почти идеальный кандидат для метода прогонки (алгоритм Томаса).

Метод прогонки

Трёхдиагональные системы можно решать через обычный Gaussian elimination, но метод прогонки делает это быстрее — за \(O(n)\) вместо \(O(n^3)\). Идея: сначала прямой ход, вычисляем вспомогательные коэффициенты \(P\) и \(Q\), потом обратный — восстанавливаем \(c\) по очереди от последнего к первому.

# Прямой ход
P[0] = −h / (4h)
Q[0] = r[0] / (4h)

for i in range(1, n−1):
    D = h·P[i−1] + 4h
    P[i] = −h / D
    Q[i] = (r[i] − h·Q[i−1]) / D

# Обратный ход
c[n−1] = Q[n−1]
for i in range(n−2, −1, −1):
    c[i] = P[i]·c[i+1] + Q[i]

Чтобы убедиться, что прогонка работает правильно, результат можно проверить через numpy.linalg.solve — они должны совпасть.

Строим сетку и считаем

import math

a, b = 0, 5

# n = 5
n1 = 5
h1 = (b - a) / n1
grid_1_x = [i for i in range(n1 + 1)]
grid_1_y = [math.cos((i * h1)**2) for i in range(n1 + 1)]

# n = 25
n2 = 25
h2 = (b - a) / n2
grid_2_x = [i * h2 for i in range(n2 + 1)]
grid_2_y = [math.cos((i * h2)**2) for i in range(n2 + 1)]

После того как коэффициенты найдены, сплайн можно вычислить в любой точке — берёшь нужный отрезок и подставляешь в формулу с a, b, c, d.

Точность: n = 5 против n = 25

Чтобы оценить точность, считаем значения в серединах каждого отрезка и смотрим на разницу между сплайном и настоящей функцией.

Параметр \(n = 5\) \(n = 25\)
Шаг сетки \(h\) 1.0 0.2
Количество отрезков 5 25
Погрешность заметная — функция быстро осциллирует на порядки меньше

Функция \(\cos(x^2)\) — коварная: чем дальше от нуля, тем чаще она осциллирует. При \(n = 5\) и шаге \(h = 1\) сплайн не успевает за этими колебаниями. При \(n = 25\) сетка намного плотнее, и точность резко возрастает. Это хорошо видно на графике: правая часть при \(n = 25\) совпадает с автосплайном почти идеально, тогда как серая линия (авто) и чёрная (ручной) заметно расходятся только там, где функция меняется особенно быстро.

Графики в коде

Для визуализации сплайн собирается как кусочная функция через sympy.Piecewise, потом «компилируется» в быстрый numpy-вариант через lambdify. Дополнительно строится «эталонный» сплайн через scipy.interpolate.CubicSpline — чтобы видеть, насколько ручной расчёт совпадает с библиотечным.

import sympy as sm

x = sm.Symbol('x')
S = sm.Piecewise(*[
    (a_k + b_k*(x - x_prev) + c_k*(x - x_prev)**2 + d_k*(x - x_prev)**3,
     (x >= x_prev) & (x <= x_next))
    for k in range(1, n+1)
], (sm.nan, True))

S_func = sm.lambdify(x, S, modules=['numpy'])

Итог

Кубические сплайны — это способ строить гладкие кривые через набор точек без взрывного роста погрешности. Ключевое: чем плотнее сетка, тем точнее результат. Для «спокойных» функций хватит небольшого \(n\), а вот для быстроменяющихся — нужно узлов побольше. Метод прогонки при этом позволяет решить систему уравнений за линейное время, что делает всю схему вполне практичной даже для больших сеток.
